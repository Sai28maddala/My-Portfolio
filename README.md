# Maddala Venkata Sailakshmi — Portfolio

Personal portfolio built with React, TanStack Start, Vite, and Tailwind CSS.

## Run locally

Install [Node.js](https://nodejs.org/) (Node 20.19+ or 22.12+), then run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Build

```sh
npm run build
npm run preview
```
